# Simple ChordPro

A Chrome extension for working with ChordPro formatted song sheets.

## Privacy Policy

Simple ChordPro does not collect or transmit any user data. All song data is stored locally in your browser using Chrome's storage API. We do not use any third-party analytics or tracking tools.

## Features

- Convert between ChordPro and Chord/Lyric formats
- Transpose songs between different keys
- Works offline
- All data stored locally

## Installation

Available on the Chrome Web Store (link coming soon)

## Development

1. Clone the repository
2. Run `npm install`
3. Run `npm start` for development
4. Run `npm run build` to create production build
